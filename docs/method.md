# しくみと評価

実装: `ambe2_neurodec/model.py`、`focalnet.py`、`istft.py`。テスト: `tests/test_decoder.py`。

## 構成

```
受信ビット [T, 49]（＋欠落のフラグ） ──────────────────────────────→ ビット埋め込み ─┐
        └→ 従来のデコーダー（ambe2-c） → 8 kHz 音声 → log-mel（80 帯域） → mel 埋め込み ─┤
                                                                                         ↓
            FocalNet（因果的な focal modulation、幅 192 × 3 段、先読み 1 フレーム）
                                                                                         ↓
     従来のデコーダーの log-mel ＋ 予測した残差 → クリーン音声の log-mel → iSTFT ボコーダー → 8 kHz
```

- **入力**: 受信した 49 bit（±1）と欠落のフラグ、および従来のデコーダーの出力の log-mel（20 ms ごと、80 帯域）。欠落したフレームはビットを 0 にし、フラグを 1 にします。従来のデコーダーには、欠落を消失として渡します（直前のフレームの繰り返しと減衰）。
- **残差の学習**: 従来のデコーダーの log-mel に、ネットワークが予測した補正を足して、クリーン音声の log-mel にします。従来のデコーダーが持つ量子化の知識（符号帳、予測、補間）をそのまま使い、ネットワークはそれを直す部分だけを学習します。
- **埋め込み**: ビットと log-mel を、それぞれ 2 層の全結合で 192 次元にして連結します。
- **FocalNet**: [FocalCodec](https://github.com/lucadellalib/focalcodec) の decompressor と同じ focal modulation のブロックです。因果モード（FocalCodec-Stream）で、時間方向の畳み込みは過去側だけを見ます。全体平均の代わりに、過去 64 フレーム（1.28 秒）の窓を使います。
- **先読み**: フレーム t の予測は、フレーム t+1 の入力まで見た位置から読みます。
- **ボコーダー**: [neurodec](https://github.com/tallcat4/neurodec) の因果的な iSTFT ボコーダー（`model.causal`）です。クリーン音声の log-mel から音声を作るように事前学習し、デコーダーの学習中は固定しました。励振の入力は、ネットワークが使わないことが分かっているので（neurodec の docs/experiments.md）、一定値を渡しています。

## 遅延

- フレーム t の音は、フレーム t+1 を受信したあと、iSTFT の重ね合わせ（256 サンプル、32 ms）の分だけ遅れて確定します。
- 出力は従来のデコーダーの出力と同じタイミングに合わせてあり、そこからの追加の遅延は 52 ms です。
- `tests/test_decoder.py` の `test_causal_model_uses_one_frame_ahead` で、フレーム t のビットを変えても、フレーム t−1 より前（から 256 サンプルを引いた位置より前）の出力が変わらないことを確かめています。

## 学習

| 項目 | 値 |
|---|---|
| 音声 | LibriSpeech train-clean-100 / 360 / train-other-500（960 時間） |
| フレーム | 8 kHz、アクティブレベル −26 dBFS、ambe2-c のエンコーダー（RATET 34）。発話ごとに全体を符号化 |
| 目標 | クリーン音声（符号化の遅延 360 サンプルだけずらしたもの）の log-mel |
| 損失 | log-mel の L1 |
| ビット誤り | 4 割のサンプルに、0〜3 % の一様なビット誤り |
| フレームの欠落 | 3 割のサンプルに、0〜10 % の欠落（1〜3 フレームの連続） |
| 最適化 | AdamW、学習率 3e-4（1000 step のウォームアップ後にコサインで減衰）、バッチ 32 × 3 秒、60000 step |
| 学習時間 | RTX 4070 Ti SUPER で約 2.5 時間（データの読み込みが律速） |

## 評価

### LibriSpeech test-clean と JSUT（250 発話）

LibriSpeech test-clean の未知話者 40 名 × 5 発話と、JSUT basic5000 の最後の 50 発話です。元の音声を 8 kHz に落とし、アクティブレベルを −26 dBFS にそろえたものと比べています。

| 受信の条件 | PESQ（NB） | STOI | log-mel 距離 | UTMOS |
|---|---|---|---|---|
| 誤りなし | 2.86 → **3.06** | 0.907 → **0.919** | 5.00 → **4.24 dB** | 2.38 → 2.31 |
| ビット誤り 1 % | 2.26 → **2.78** | 0.850 → **0.899** | 5.57 → **4.52 dB** | 1.73 → **2.13** |
| ビット誤り 3 % | 1.73 → **2.36** | 0.765 → **0.864** | 6.57 → **5.00 dB** | 1.32 → **1.80** |
| フレームの欠落 約 5 % | 2.46 → **2.80** | 0.878 → **0.905** | 5.37 → **4.43 dB** | 2.20 → 2.20 |
| フレームの欠落 約 10 % | 2.22 → **2.61** | 0.850 → **0.890** | 5.79 → **4.63 dB** | 2.04 → **2.08** |

（従来のデコーダー → `ambe49_causal_v1`。UTMOS は 8 kHz の音声なので全体に低く出ます）

### 上限

正解（クリーン音声）の log-mel をボコーダーに入れたときの値です（125 発話）。

| | PESQ（NB） | STOI | log-mel 距離 |
|---|---|---|---|
| このリポジトリの因果的なボコーダー | 3.59 | 0.953 | 3.08 dB |
| 参考: neurodec の非因果的なボコーダー | 3.73 | 0.961 | 2.39 dB |

このデコーダー（誤りなしで 3.06）と上限との差は、ビットから log-mel を予測する部分の誤差です。

## モデルの大きさ

FocalNet の幅だけを変えて、同じ条件（960 時間、60000 step）で学習しました。ボコーダー（約 170 万パラメータ）は共通です。

| FocalNet の幅 | パラメータ数（全体） | 誤りなし | ビット誤り 1 % | ビット誤り 3 % | 欠落 約 5 % | 欠落 約 10 % |
|---|---|---|---|---|---|---|
| 従来のデコーダー | — | 2.86 | 2.26 | 1.73 | 2.46 | 2.22 |
| **192（このリポジトリ）** | **約 340 万** | **3.06** | **2.78** | **2.36** | **2.80** | **2.61** |
| 256 | 約 470 万 | 3.09 | 2.86 | 2.46 | 2.85 | 2.67 |
| 768 | 約 2640 万 | 3.20 | 3.02 | 2.70 | 2.99 | 2.81 |

（PESQ（NB）、250 発話）

- **数値の差**: 誤りが多い条件ほど、大きいモデルとの差が開きます（誤りなしで 0.14、ビット誤り 3 % で 0.34）。
- **ABX テスト**: 幅 768 と幅 192 の出力を、日本語の 40 問で聞き比べました。
  - 音声: JSUT 20 発話、ReazonSpeech 18 発話（男女 9 ずつ）、試聴用の例（Qwen3-TTS）の 2 発話。
  - 条件: 誤りなし 12 問、ビット誤り 1 % 6 問、3 % 8 問、欠落 約 5 % 6 問、約 10 % 4 問、ビット誤り 3 % ＋ 欠落 約 10 % 4 問。
  - 結果: 25/40 問の正解（片側二項検定 p = 0.077）で、5 % 水準では聞き分けられませんでした。誤りなしは 7/12 で偶然と同じ程度、ビット誤り 3 % だけは 7/8 でした（1 人の聞き手、条件ごとの問数は少ない）。
- **選んだ理由**: 誤りなしや軽い誤りでは聞き分けられず、すべての条件で従来のデコーダーより良いため、小さい幅 192 を採用しました。

## 検討した構成

| 構成 | 結果 |
|---|---|
| FocalCodec（50 Hz）の WavLM 特徴量を予測し、FocalCodec の Vocos で合成（16 kHz） | 正解の特徴量を入れても PESQ（NB）2.33 で、従来のデコーダー（2.86）に届かないため不採用 |
| 従来のデコーダーの log-mel を、学習なしでボコーダーに入れる | PESQ 2.77（下限） |
| 非因果的な構成（発話全体を見る、全体平均あり） | 誤りなしで PESQ 3.29、ビット誤り 3 % で 2.85。因果的な構成より 0.1〜0.15 高いが、受信しながらの復号ができない |
| 因果的な構成で、全体平均の代わりの窓を 512 フレームにする | 学習が約 3 倍遅いため、64 フレームにした（品質の比較はしていない） |
| 出力を 24 kHz の Vocos にする（帯域の拡張） | 正解の mel での上限は PESQ（NB）3.99、UTMOS 3.58（8 kHz のボコーダーは 2.73）。学習は未実施 |
